# «Сбор утреннего урожая» — трекер Алексея Солнцева

Публичный трекер покерных сессий Алексея Солнцева (друг Романа). Сделан на основе сайта марафона Романа (`rserbatyh680-arch/marathon`), но с другим дизайном: главное — график профита. Общение с Романом на русском и на «ты». Сессии Алексей вносит сам через форму на сайте по ключу.

- Сайт: https://rserbatyh680-arch.github.io/harvest/ (GitHub Pages, ветка `main`, корень)
- Репозиторий: `rserbatyh680-arch/harvest` (на аккаунте Романа). Пушить в `main`.

## Файлы
- `index.html`: весь сайт (HTML + CSS + JS, без сборки).
- `data.json`: `{settings, sessions}`. Гости читают его с raw.githubusercontent.com (не ждут пересборки Pages), запасной вариант — копия на сайте. Автор пишет через GitHub Contents API своим ключом (fine-grained токен только на этот репозиторий, Contents: read/write), ключ хранится в его браузере (`localStorage`, ключ `harvest-gh-token`).
- `avatar.jpg`: фото Алексея.
- Скрины заносов: массив `WINS` в index.html (`["win1.jpg","подпись"]`), файлы рядом. Пока пусто — кнопка «Заносы» скрыта.

## Модель данных
Сессия: `date, ts, mtt, rooms[8], withdraw, rakeback, buyins, turbo (кол-во турбо-турниров в сессии), note`.
Румы (8, константа ROOMS): GGPoker, PokerStars, Winamax, PokerStars.es, RedStar, ACR, CoinPoker, Chico. Кошельков нет.
Settings: `rooms, startBR, startDate, hu {played, won}`.

## Логика
- БР = сумма румов. Результат сессии = ΔБР + вывод − рейкбек. Профит = сумма результатов; первая сессия считается от `startBR`.
- ROI = профит сессий с бай-инами / сумма бай-инов. АБИ общий = бай-ины / турниры; «играю сейчас» = АБИ последней сессии.
- Турбо-кэф: в сессии = турбо / турниров; общий = все турбо / все турниры.
- Шапка: название зелёным градиентом, рамка аватара лаймовая (#9dff3c), за шапкой всплывают крупные разноцветные «ачивки» с суммами и кубками (случайные суммы от $1 000 до $10 000, иногда «1-е место»/«Финалка»). Блок итогового банкролла под румами убран по просьбе Романа.
- График профита — герой страницы, под датами накопленное число турниров, сессии с заметкой отмечены зелёной точкой.

## История
Сессии с 15 авг по 7 окт 2026 восстановлены приблизительно (`source: "history"`, генератор не в репо): 43 сессии, 640 турниров, АБИ 65, профит 10 800$, ROI 26%. Стартовый БР 21 100$ = текущий БР 31 900$ − профит (считаем, что выводов/пополнений не было). Остатки на 7 окт — реальные со слов Романа. Заносы внутри истории условные, турбо не заполнен.
